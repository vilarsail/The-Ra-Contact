# 导读：Ra Session 088

> **阅读指引：** 本章是 Ra 通讯中一个重要的转折点——正式开启了塔罗与原型心智的系统阐述。Ra 追溯了塔罗在金星第三密度中的起源，揭示了其作为发展魔法人格的训练工具的本质，并提供了二十二个原型的具体教学顺序与方法。

## 核心议题

* **塔罗的起源与本质：** Ra 阐明塔罗概念起源于金星第三密度人口，是"许多、许多世代"在原型心智上工作的产物，被用作发展魔法人格的训练辅助工具。那些最初部分穿透面纱的金星实体收集了关于原型心智与面纱过程的信息，由此设计了塔罗作为教导工具。Ra 指出，在其第三密度工作完成后取得的一个重大突破，是对第二十二号奥秘"选择"给予了适当的强调——Ra 自身虽意识到这一统一性原型的存在，但未曾赋予其充分的概念复合体。

* **原型心智的独立性与教学方法：** 发问者试图将原型理解为作用于心/身/灵三个部分的重复模式，但 Ra 纠正了这一根本性误解：每个原型都是一个"ding an sich"（自在之物），拥有其独立的概念复合体。原型心智赋予思想以信息，随后影响心智、身体或灵性，但原型与身体或灵性并无直接联系——一切必须通过潜意识心智的更高层次被抽取到显意识。Ra 的教学方法是口耳相传的持续观想训练，而非使用卡片。

* **二十二个原型的教学顺序：** Ra 详细描述了其训练课程：第一阶段按"一、八、十五；二、九、十六……"的垂直分组呈现图像，使学生发现心智、身体与灵性之间的基本关系；第二阶段引入配对考量（如心智母体与赋能者）；第三阶段引导学生学习"成为每个原型"，并在幻象中辨别何时采用原型的角色对灵性或形而上发展有益。Ra 强调"我们没有教条可以提供"，每个启蒙者创造性地感知对自我而言必要和有益的东西。

* **塔罗与占卜的分离：** Ra 明确将大奥秘（作为原型心智的二十二个原型代表）与塔罗占卜方法分离开来。占星术有其价值——行星影响进入星球的能量网络，如同月亮移动海洋之水——但大奥秘本身在占卜中没有正当位置，它们"是自我用来进一步认识自我的工具，目的是进入一个更深刻、更敏锐地实现的当下时刻"。

## 关键概念提炼

* **自在之物（Ding an Sich）：** Ra 以德语哲学概念描述每个原型的本质——每个原型是不可被简化的独立存在，拥有其自身的"旋律"或"格式塔"，审视原型间的关系虽是启发性的，但次于发现每个原型对智力和直觉心智所意味的最纯粹的本质。

* **魔法人格（Magical Personality）：** 塔罗作为发展魔法人格的训练工具，其最终目标是使启蒙者能够根据情境需要，在灵性或形而上层面自觉地"成为"某个原型。
