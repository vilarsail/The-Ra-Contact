- **全篇总括**：本集承接上集，讲星际联邦在埃及的两次古接触：先在空中短暂现身，因当地没有足够呼求而离场；再以"兄弟"身份现身、靠思想形态建成大金字塔，却因"每说一词便传出三十个印象"及教导随后被扭曲而收场。后半集借阿肯那顿的结局、当地疾病的根因与南美平行案例，追问"失败"究竟该如何定义。
  - **埃及首次接触：在没有呼求的地方，露面也没有意义**
    - **发问者的追问**：接着昨天的话头——联邦在第三主要周期首次接触时，为何选择埃及，又抱着什么样的心态前往？
    - **当时的局面**：约一万八千年前，当地人正崇拜鹰首太阳神"荷鲁斯"（Horus，Ra 称作"振动声音复合体"），所拜对象实为太阳圆盘的种种变貌（distortion，对统一性的任何偏离状态）
      - **联邦的做法**：先"扫台"——像调频收音机一样扫描人群，看是否存在严肃到足以构成"呼求"的寻求
        - **扫描结果**：该社会复合体的宗教信仰自相矛盾，没有与联邦振动相称的呼求
      - **结论**：无呼求即不干涉，联邦未采取任何行动便离开
    - **他们看到了什么**：目击者看到的是"水晶动力的钟形飞行器"
      - **为何没改变他们**：他们坚信世上本就有众多神明操控超自然事件，奇景属于常态
      - **为何选择可见**：Ra 说得很直白——因为"可见与不可见并无差别"
  - **埃及第二次接触：从"兄弟现身"到思想形态造塔**
    - **衔接**：首次空手而归后，联邦又试了一次，这次持续了很长时间
    - **决策点**：判断当地已积蓄足够的呼求，于是决定以兄弟身份行走于人群之中
      - **向土星议会报备**：申请以"直接降落于内在层面、不经投生过程"的服务型游荡者（wanderer）身份前来
      - **物质化现身**：以尽量贴近自身本质的"物理-化学复合体"出现，准备担任一段时间的《一的法则》教师；理由是当地对太阳体的兴趣日益增强，而太阳振动与联邦自身的变貌同频
    - **失败的机制**：每说出一句话，他们的存在本身已先传出约三十个印象，反而令被服务者混淆 → 短期内主动撤走，转而用很长时间研究"怎样才是最好的服务"
    - **转向金字塔**：注意到亚特兰蒂斯人已构想出以金字塔形疗愈的方案
      - **二次报备**：针对埃及与亚特兰蒂斯两地文化变貌的差异作出调整，再次向土星议会提交计划，目标是协助当地的疗愈与长寿，同时传述《一的法则》哲学 → 议会再次批准
    - **落地时间线**：
      - 约一万一千年前以思想形态进入（Ra 此处出现一次自我更正，并说明器皿生命力偏低导致表达吃力）
      - 约八千五百年前回到该行星复合体的思想形态区域，花数年研究如何恰当建造这些结构
      - 约六千年前建成第一座，即大金字塔——"以思想完成其建筑"
      - 此后改用更偏"当地、地球"的材料，依序建造其余金字塔形结构，持续约一千五百年
      - 与此同时，关于水晶入修（initiation）与疗愈的信息也在传递
    - **阿肯那顿**：他能几乎无变貌地领受这些信息，一度倾尽全力推行《一的法则》，并按入修与真正慈悲疗愈的要求重整祭司体系，但未能持久
      - **结局**：他一离开第三密度的肉身，教导便迅速被扭曲，金字塔重新落入所谓"王家"、即那些偏向权力者之手
  - **金字塔疗愈：真正要疏通的是哪一层**
    - **发问者的预设**：他以为金字塔疗愈主要是治"心智"
    - **Ra 的修正**："部分正确"——疗愈若要真正生效，必须把流入的能量经由灵性复合体、无显著变貌地导入"心智之树"；心智中有些部分会阻断流向身体复合体的能量
    - **关键次序**：先激活灵性通道／往返梭（shuttle）的感知，之后才谈得上疗愈
      - **三种阻塞**：由灵到心的阻塞、由心到身的阻塞，或纯粹偶然的物理创伤——不论哪一种，都可施疗
      - **个体差异**：每个实体的阻塞位置都可能不同
  - **吉萨建造的现场与"大建筑师"**
    - **发问者想确认**：以思想建塔时，联邦是否与投生的埃及人有直接接触？他们是否目睹？
    - **Ra 的回答**：当时并无密切接触；联邦回应的是当地足够强的"总呼求"，把思想发送给所有寻求者
    - **奇观与巧合**：金字塔的出现引起极大惊讶
      - **刻意安排**：它的显现被精心安排，与一位"大建筑师"的投生相合
      - **后果**：该实体后来被神化，部分原因正是这次事件
      - **神名**：这位被神化的实体，其振动声音复合体是"伊姆霍特普"（Imhotep）
  - **成败评估：是责任，不是失败**
    - **发问者的追问**：抛开"未带来预期的意识提升"，金字塔一事究竟有没有成功之处？
    - **Ra 的第一层回答**：请记住我们属于"忧伤的兄弟姐妹"——当人从忧伤中被救出、得见太一造物者，就不存在"失败"这个概念
    - **真正的重量**：难点在于"荣誉／责任"——须纠正联邦在助人过程中造成的《一的法则》变貌
      - **重新定性**：这些变貌应被视为责任而非失败；少数因此被激发去寻求的人，就是当初尝试的唯一理由
    - **悖论**：有人因此得启迪，按"你们的标准"即为成功；另一些人变得更忧伤困惑，即为失败——Ra 强调"这些是你们的用词"，而他们只是继续寻求服务
    - **混淆法则下的拒答**：发问者明知会被拒仍要问——本月晚些时候亨利·普哈里奇（Henry Puharich）将来访，他觉得有义务代问此人是否卷入过上述任何一个时期
      - **Ra 的回应**：无法就"亨利"这个实体说任何话；并提示——去看看该实体关于"证据（proof）"的变貌，就能理解联邦的处境
  - **阿肯那顿之后：高起点的教导为何败落，以及疾病的根因**
    - **他的死后**：经历第三密度应有的一系列疗愈与投生回顾
      - **关键张力**：他本身带有偏权力的变貌，被对《一的法则》的巨大虔诚所缓和
      - **他的选择**：因此决心进入一系列"不含权力变貌"的投生
    - **当时的寿命**：埃及人平均约三十五到五十岁，身体层面的疾病很多
    - **表层机制**：Ra 先声明这"对《一的法则》信息量不大"，再给出直接原因——当时居住条件相当野蛮
      - **尼罗河**：任由河水泛滥与消退，形成的沃土成为昆虫传播疾病的温床
      - **食物**：食物的处理方式使疾病得以形成
      - **水源**：水源本身有问题，水中的微生物致病
    - **更根本的成因**：发问者不满足于"传播机制"，追问到思想根层
      - **他的假设**：地球上长期对《一的法则》理解的整体退化，制造了疾病得以发生的条件 —— Ra 判定："正确，且有洞察力，你已开始穿透外层教导"
      - **Ra 补的根因**：该社会的主因并非好战，而是**金钱体系**的形成，以及随之活跃的贸易与"贪婪—权力"倾向的发展
        - **后果**：实体彼此奴役，并误解了每个实体内在的造物者
  - **南美接触：近乎翻版的平行剧本**
    - **衔接与提问**：发问者转而追问南美接触的心态、计划与缘起；Ra 提示这是本集最后一个完整问题
    - **起因**：当地实体同样渴望了解太阳的显现，崇拜这光与生命之源 → 于是被与我们相类的光之存有造访
      - **相对顺利**：所给指引被接受的程度更高、扭曲更少
    - **建造**：他们自行开始建造一系列地下与隐蔽城市，其中包含金字塔结构
      - **与联邦设计的差异**：这些金字塔与联邦颁布的设计有些出入，但基本理念相同
      - **新增意图**：要造出供冥想与休息、感受太一造物者临在的场所，而且面向所有人，不再只限于入修者与待疗愈者
    - **第一次离开**：当计划已稳固推进并被记录下来，他们便离开这个密度
      - **之后约三千五百年**：计划虽有变貌，许多方面仍接近完成
    - **隔离被打破后的补救**：与所有"破坏隔离（quarantine）"的情形一样，协助南美实体（部分即沿亚马逊河一带）的实体前往土星议会，请求第二次亲自纠正错谬
      - **获准之后**：该实体或其社会记忆复合体（social memory complex，众多个体共享同一心智与记忆的群体）返回，被选为信使的那位再次来到人群中纠错
      - **又一次离开**：一切同样被记录，该实体重归其社会记忆复合体，离开你们的天空
    - **同样的堕落**：教导大部分被严重扭曲，后来甚至演变成以真人献祭取代对人的疗愈
      - **同样的责任**：因此这个社会记忆复合体也被赋予"留待此地、直到这些变貌从人群的变貌复合体中被消解"的荣誉／责任
