# 技能：生成《一的法则》单章导读 (Generate The Ra Contact Session Guide)

## 技能描述
这是一个专门用于为《一的法则》（The Ra Contact）各章节生成详尽、具体的阅读导读（Reading Guide）的代理。它通过通读单篇 Markdown 原文的英文段落（跳过中译段落以避免上下文冗余），深入提炼核心议题与关键形而上学概念，并充分还原原文的丰富层次与抽象深度，帮助读者在阅读正文前建立扎实的认知框架。

## 触发指令
`/guide_ra start=<起始章节> end=<结束章节>`

## 文件权限与路径定义
* **数据来源 (仅读取 Read-Only)：** `./split/Ra_Session_XXX.md`
* **导读输出 (仅写入 Write-Only)：** `./output/Ra_Session_XXX_guide.md`
* **双语对照处理：** 原文为英中逐段对照格式（英文段落后紧跟中文翻译段落，二者内容重复）。**仅读取英文原文段落进行导读生成，跳过中文翻译段落**，以避免上下文冗余。判定方式：段落以 `(X.X) Ra I am Ra...` / `(X.X) Questioner...` / 纯英文开头者保留；以 `(X.X) Ra 我是 Ra...` / `(X.X) 发问者...` / 含中文字符的对应翻译段落跳过。中括号注释如 `[Two-minute pause.]` / `[两分钟停顿.]` 同样只保留英文版本。

## 核心规则与约束
1. **单文件串行处理：** 必须按照 `XXX` 编号单文件顺序独立处理。处理完当前章节并写入导读后，必须彻底清空上下文缓存，才能进入下一章，严禁多章合并读取。
2. **字数与弹性控制：** 
   * **不限固定长度：** 不再设定标准字数区间。导读篇幅应依据原文长度与内容丰富程度自由扩展，充分覆盖章节所涉及的核心议题、抽象概念及关键论证脉络。
   * **扩展原则：** 当原文篇幅较长、问答密集、或涉及复杂的形而上学/宇宙学概念（如：塔罗牌架构、特定密度的详细演化、星际联邦的历史、催化剂与变貌的多层作用机制等）时，应主动加深描述，具体呈现概念之间的关联、Ra 所阐述的机制细节，以及发问者的追问与 Ra 的回应脉络，避免一笔带过。
   * **上限约束：** 最终导读文本总长不超过 **2000字（中文字符）**。在接近上限时，应优先保留对理解原文最关键、最抽象、最易混淆的部分，进行充分阐释。
   * **避免空泛：** 扩展的目标是"具体"而非"冗长"。应避免用套话填充篇幅，确保每一句话都承载实质信息或概念澄清。
3. **内容风格与去宗教化：** 保持中立、学术、形而上学的探讨口吻。使用《一的法则》的标准术语（如：变貌、心/身/灵复合体、催化剂等），避免使用世俗化或带有浓重人类情感色彩的过度总结。
4. **输出语言与术语映射：** 导读以**中文**输出。由于仅读取英文原文，生成时需将英文概念准确映射到《一的法则》的通行中文术语体系，关键术语对照参考（非穷举，遇到未列出的概念应采用社区通行译法）：

   * `beam` → 波束
   * `catalyst` → 催化剂
   * `Confederation` / `Confederation of Planets` → 星际联邦
   * `density` → 密度
   * `distortion` → 变貌（在描述形而上学的偏差/状态时统一使用"变貌"）
   * `gateway` / `portal` → 门户
   * `harvest` → 收割
   * `I am Ra.` → 我是 Ra。
   * `Infinite Creator` → 无限造物主
   * `Intelligent Infinity` → 智能无限
   * `Law of One` → 一的法则
   * `light and love` / `light/love` → 光与爱 / 光/爱
   * `Logos` → 逻各斯
   * `love and light` / `love/light` → 爱与光 / 爱/光
